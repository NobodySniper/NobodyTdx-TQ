## 中文主视图

### 目录结构

```
strategies/
├── __init__.py    ← 注册中心（新增策略在这里注册）
├── base.py        ← 基类（不用改）
├── ma_cross.py    ← 示例策略
└── 你新建的.py     ← 你的新策略
```

### 新增策略只需 2 步

#### 第 1 步：新建策略文件 `strategies/my_strategy.py`

```python
from .base import BaseStrategy
import backtrader as bt

class MyStrategy(BaseStrategy):
    params = (
        ('param1', 10),
        ('param2', 20),
    )

    def __init__(self):
        super().__init__()   # 必须调用，初始化 order / trade_records 等
        # 在这里定义指标
        self.ma = bt.indicators.SMA(self.data.close, period=self.p.param1)

    def next(self):
        self.bar_count += 1
        if self.order:       # 有未成交订单就跳过
            return
        if not self.position:
            # 空仓 → 满足条件买入
            if 买入条件:
                self.order = self.buy()
        else:
            # 持仓 → 满足条件卖出
            if 卖出条件:
                self.order = self.sell()
```

#### 第 2 步：注册策略

打开 `strategies/__init__.py`，在 `_registry` 字典加一行：

```python
_registry = {
    'ma_cross': ('ma_cross', 'MaCrossStrategy'),
    'my_strategy': ('my_strategy', 'MyStrategy'),   # ← 加这行
}
```

### 切换策略

修改 `config.py`：

```python
STRATEGY_KEY = 'my_strategy'
```

### 策略参数与前端表单

策略通过 `_user_params` 声明暴露给前端的参数，前端自动渲染表单，backtest 自动传参。

#### 声明格式

```python
class MyStrategy(BaseStrategy):
    params = (
        ('rsi_period', 14),
        ('overbought', 70),
    )

    # 暴露给前端的参数（前端自动渲染输入框，backtest 自动传参）
    _user_params = [
        {'key': 'rsi_period', 'label': 'RSI周期', 'type': 'int', 'default': 14},
        {'key': 'overbought', 'label': '超买阈值', 'type': 'int', 'default': 70},
    ]
```

| 字段 | 说明 |
|------|------|
| `key` | 参数名，必须与 `params` 里的名字一致 |
| `label` | 前端表单显示的中文标签 |
| `type` | `int` / `float` / `str`，控制输入框类型 |
| `default` | 默认值 |

#### 当前 ma_cross 的参数声明

| key | label | type | default |
|-----|-------|------|---------|
| `fast_period` | 快线周期 | int | 10 |
| `slow_period` | 慢线周期 | int | 20 |

### 基类提供的自动功能

| 功能 | 说明 |
|------|------|
| `self.order` | 当前未成交订单对象，`None` 表示空闲 |
| `self.position` | 当前持仓，`bool(self.position)` 判断是否持仓 |
| `self.bar_count` | 已处理 K 线根数 |
| `self.buy()` / `self.sell()` | 发送买卖信号（size 由 sizer 决定） |
| `self.trade_records` | 自动收集的完整交易列表（CSV 导出用，无需手写） |
| `self.log(msg)` | 控制台日志输出 |

### 数据字段与约束

**数据源**：通达信 TQ API → 日线前复权 → backtrader PandasData feed

| 字段 | DataFrame 列 | 策略访问方式 | 类型 |
|------|-------------|-------------|------|
| 开盘价 | open | `self.data.open[0]` | float |
| 最高价 | high | `self.data.high[0]` | float |
| 最低价 | low | `self.data.low[0]` | float |
| 收盘价 | close | `self.data.close[0]` | float |
| 成交量 | volume | `self.data.volume[0]` | float |
| 日期时间 | index | `self.datas[0].datetime.datetime(0)` | datetime |

**约束**：
- 仅有上述 5 个 OHLCV 字段，无成交额/换手率/委比等扩展字段
- 日期索引为回测起始日 ~ 昨日，非交易日无数据
- 策略中可使用的指标必须基于上述 5 个字段计算
- 不允许引入通达信不兼容的外部库（如 talib 的 C 扩展部分、numba 等）

### 完整示例：双均线金叉死叉

```python
from .base import BaseStrategy
import backtrader as bt

class MaCrossStrategy(BaseStrategy):
    params = (
        ('fast_period', 10),
        ('slow_period', 20),
    )

    def __init__(self):
        super().__init__()
        self.ma_fast = bt.indicators.SMA(self.data.close, period=self.p.fast_period)
        self.ma_slow = bt.indicators.SMA(self.data.close, period=self.p.slow_period)
        self.cross = bt.indicators.CrossOver(self.ma_fast, self.ma_slow)

    def next(self):
        self.bar_count += 1
        if self.order:
            return
        if not self.position:
            if self.cross[0] > 0:    # 金叉买入
                self.order = self.buy()
        else:
            if self.cross[0] < 0:    # 死叉卖出
                self.order = self.sell()
```


## Machine-Readable Key Reference

### Strategy Template Contract

```yaml
# _machine
StrategyClass:
  inherits: BaseStrategy
  required_methods:
    - __init__: # must call super().__init__()
    - next:     # signal logic only
  must_not_override:
    - notify_order   # handled by BaseStrategy
    - notify_trade   # handled by BaseStrategy
    - log            # handled by BaseStrategy
  auto_provided:
    - self.order          # pending order object or None
    - self.position       # current position
    - self.bar_count      # bar counter
    - self.trade_records  # list of completed trades dicts
  trade_records_schema:
    fields:
      - 开仓日期: str (YYYY-MM-DD)
      - 开仓价: float
      - 平仓日期: str (YYYY-MM-DD)
      - 平仓价: float
      - 持仓数量: int
      - 毛利盈亏: float
      - 净盈亏: float
      - 是否盈利: "是" | "否"

Registry:
  file: strategies/__init__.py
  format: _registry = {'key': ('module_name', 'ClassName')}

Config:
  file: config.py
  field: STRATEGY_KEY   # registry key to load
```
