# 便携包方案（待实施）

## 目标

用户不装 Python、不 pip install，解压即用。

## 原理

- 通达信不自带 Python，走用户系统的 Python
- `tqcenter.py` 是普通 .py 文件，放在 `PYPlugins\user\` 目录下
- Python 从当前工作目录找到它
- 通达信客户端运行时，tqcenter 内部通过进程通信和通达信交互

## 方案

打包内容：

```
qq798623backtest/
├── python/                      ← 嵌入式 Python（~30MB）
│   ├── python.exe
│   └── Lib/
│       └── site-packages/       ← 所有 pip 依赖打包在这里
│           ├── backtrader/
│           ├── flask/
│           ├── pandas/
│           ├── numpy/
│           ├── matplotlib/
│           └── ...
├── strategies/
├── webapp/
├── config.py
├── backtest.py
├── ...
└── start.bat                    ← 用自带的 python.exe，不走系统 PATH
```

## start.bat 逻辑

1. 工作目录切到 `PYPlugins\user\`（tqcenter.py 在这里）
2. 用自带 `python\python.exe` 运行 `qq798623backtest.webapp.app`
3. 自带 site-packages 优先于系统 Python 的库
4. 不需要设 PYTHONPATH（tqcenter.py 在 cwd 下自动找到）

## 用户体验

1. 安装通达信终端 → 启动
2. 解压项目到 `PYPlugins\user\`
3. 双击 `start.bat`
4. 浏览器打开 `http://127.0.0.1:5119`
5. 不装 Python、不 pip install

## 打包步骤（待执行）

1. 下载 Python 3.12 嵌入式版（python-3.12.x-embed-amd64.zip）
2. 解压到 `qq798623backtest/python/`
3. 用当前环境的 pip 安装依赖到便携目录：
   ```bash
   pip install -r requirements.txt --target=python/Lib/site-packages
   ```
4. 修改 `start.bat` 用 `python\python.exe` 而非系统 Python
5. 测试 tqcenter 能否正常工作

## 注意事项

- 嵌入式 Python 默认不启用 site-packages，需要配置 `python312._pth` 文件
- pandas/numpy 有 C 扩展，需要对应平台的 wheel
- matplotlib 字体文件需要一起打包（中文字体 SimHei/YaHei）
- __pycache__ 目录不需要打包

## 注意事项

- `python/Lib/site-packages/` 里有 `__pycache__` 和 `.dist-info` 目录，打包 zip 时可以省略以减小体积
- matplotlib 字体依赖系统已安装的 SimHei/Microsoft YaHei，用户 Windows 自带无需额外处理
- 便携 Python 依赖 VC 运行时（`vcruntime140.dll`），已包含在嵌入式包中
- tqcenter.py 需要通达信客户端运行时才能工作，回测时必须启动通达信
